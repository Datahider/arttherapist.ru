# Контракт сайта arttherapist.ru

## Назначение

Сайт представляет арт-терапевта Наталью Харитон, объясняет формат работы и ведёт посетителя в Telegram. Он работает без WordPress, базы данных и панели администратора.

## Страницы

### Главная `/new/`

- Представляет Наталью и индивидуальную арт-терапию.
- Содержит исходные фотографии, тексты, этапы работы и отзывы действующего сайта.
- Содержит ссылку на программу «Трансформация».
- Основные призывы к действию открывают Telegram `Nata_lia1`.

### Программа `/new/transform/`

- Переносит содержание действующей страницы `/transform2/`.
- Обе кнопки «Записаться» ведут на Telegram с заранее заполненным сообщением о программе.

## Архитектура

- Каждая публичная страница — короткая точка входа PHP.
- Повторяющиеся `head`, шапка и подвал подключаются из `templates/`.
- Страница передаёт layout-шаблону заголовок, описание, идентификатор активного раздела и путь к шаблону содержимого.
- Ссылки и ассеты должны работать как в `/new/`, так и после переноса сайта в корень домена.
- Добавление страницы не требует копирования шапки или подвала.
- Неиспользуемые демо-страницы WordPress не переносятся.

## Качество

- Валидная адаптивная вёрстка без внешних JavaScript-библиотек.
- Навигация и контент доступны без JavaScript.
- Изображения имеют альтернативные подписи и ленивую загрузку вне первого экрана.
- На узком экране нет горизонтальной прокрутки.
- Страница содержит уникальные `title` и `description`.

## Публикация

- Деплой выполняется `deploy.sh` через `rsync`.
- Цель: `/home/arttherapist/apps/arttherapist-site`.
- `/home/arttherapist/htdocs/arttherapist.ru/new` — симлинк на каталог `public` приложения.
- Существующий WordPress и его файлы не изменяются.
