# Контракт сайта arttherapist.ru

## Назначение

Сайт представляет арт-терапевта Наталью Иоанниди, объясняет формат работы и ведёт посетителя в Telegram. Он работает без WordPress, базы данных и панели администратора.

## Страницы

### Главная `/`

- Представляет Наталью и индивидуальную арт-терапию.
- Содержит исходные фотографии, тексты, этапы работы и отзывы действующего сайта.
- Содержит ссылку на программу «Трансформация».
- Основные призывы к действию открывают Telegram `Nata_lia1`.

### Программа `/transform/`

- Переносит содержание действующей страницы `/transform2/`.
- Обе кнопки «Записаться» ведут на Telegram с заранее заполненным сообщением о программе.

### Посадочная страница `/mama/`

- Обращается к мамам, которые переживают эмоциональное или материнское выгорание.
- Использует имя специалиста Наталья Иоанниди.
- Предлагает индивидуальную онлайн-программу из пяти арт-терапевтических встреч и бесплатное 25-минутное знакомство.
- Основные призывы к действию открывают Telegram `Nata_lia1` с заранее заполненным сообщением.
- Посетитель может вместо прямого сообщения отправить короткую анкету: имя, Telegram и удобное время для знакомства.
- После отдельного согласия на обработку персональных данных анкета доставляется Наталье служебным Telegram-ботом.
- Подробности психологического запроса и сведения о здоровье через анкету не собираются.
- Использует общие шапку, подвал, стили и изображения сайта.
- Не имеет входящих ссылок с главной страницы и не включается в sitemap.

### Политика `/privacy/`

- Указывает оператора персональных данных: ИП Иоанниди Наталья Николаевна, ИНН 772578058869, ОГРНИП 323774600482821.
- Описывает обработку данных из анкеты `/mama/`, порядок отзыва согласия и срок хранения.
- Не включается в sitemap и доступна по ссылке возле согласия в анкете.

## Архитектура

- Каждая публичная страница — короткая точка входа PHP.
- Повторяющиеся `head`, шапка и подвал подключаются из `templates/`.
- Страница передаёт layout-шаблону заголовок, описание, идентификатор активного раздела и путь к шаблону содержимого.
- Ссылки и ассеты работают из корня домена и на вложенной странице `/transform/`.
- Добавление страницы не требует копирования шапки или подвала.
- Неиспользуемые демо-страницы WordPress не переносятся.
- Общий подвал содержит ссылку на документы Натальи об образовании.

## Качество

- Валидная адаптивная вёрстка без внешних JavaScript-библиотек.
- Навигация и контент доступны без JavaScript.
- Изображения имеют альтернативные подписи и ленивую загрузку вне первого экрана.
- На узком экране нет горизонтальной прокрутки.
- Страница содержит уникальные `title` и `description`.

## Аналитика

- На всех страницах установлен счётчик Яндекс Метрики `113678955` через общий layout.
- Код счётчика используется в выданном Яндексом виде, включая `ssr`, Вебвизор, карту кликов, ecommerce, точный показатель отказов и отслеживание ссылок.
- Для посетителей без JavaScript используется пиксель `https://mc.yandex.ru/watch/113678955`.

## Первый экран программы

- Использует два режима: двухколоночный и мобильный.
- В двухколоночном режиме фотография может только уменьшаться вслед за своей колонкой и целиком остаётся на персиковом фоне.
- Диагональная граница фона привязана к колонке фотографии, а не к ширине окна браузера.
- Заголовок масштабируется в пределах текстовой колонки и не пересекает фотографию.
- Мобильный режим включается в точке, где двум колонкам становится тесно; эта точка не обязана совпадать с остальными блоками сайта.

## Публикация

- Деплой выполняется `deploy.sh` через `rsync`.
- Цель: `/home/arttherapist/apps/arttherapist-site`.
- `/home/arttherapist/htdocs/arttherapist.ru/new` — симлинк на каталог `public` приложения.
- Существующий WordPress и его файлы не изменяются.

## Переключение в корень домена

- Canonical и Open Graph URL указывают на итоговые адреса в корне `https://arttherapist.ru/`.
- Старый действующий адрес `/transform2/` отвечает постоянным редиректом на `/transform/`.
- `/robots.txt` разрешает индексацию и указывает на `/sitemap.xml`.
- Sitemap содержит только главную страницу и программу `/transform/`.
- Демо-страницы WordPress не перенаправляются и не включаются в sitemap.
